{# Chart primitives for /stats. Two shapes cover every chart on the page: a ranked list of horizontal bars, and a row of vertical columns. Both are HTML — the labels, values and layout are real text in real boxes, so they inherit the site's type, wrap properly, translate, and stay crisp at any width. The only drawn part is the bar itself, and it is a one-rectangle SVG with `preserveAspectRatio="none"`: the box stretches to whatever CSS gives it, and the rect's `width`/`height` are SVG GEOMETRY ATTRIBUTES, not CSS. That distinction is the whole trick — the strict CSP (style-src 'self') drops inline style attributes, so `style="width:64%"` would silently render every bar at zero, and sizing them from JS would leave a no-JS visitor with an empty page. Attributes are neither. Nothing here needs a script. Non-uniform scaling would distort strokes and text, so the rects are fill-only and every label lives outside the SVG. Rows arrive from app/stats.py already reduced to {label, value, pct, peak, band}; `pct` is measured against the series maximum and `band` is that magnitude quantised to three steps of the accent ramp, with `peak` (the single highest row) taking the accent at full strength. These macros do no arithmetic beyond flipping a column's origin — the ramp is a class name, never a computed colour, because a colour computed here would have to arrive as an inline style and the CSP would drop it. #} {# ---- ranked horizontal bars: label / bar / value ------------------- #} {% macro bars(rows) %}
    {% for r in rows %}
  1. {{ r.label }} {{ r.value }}
    2. {% endfor %}
{% endmacro %} {# same, but each row links into the album it measures. The folded "+n more" tail row has no album and stays plain text. #} {% macro album_bars(rows) %}
    {% for r in rows %}
  1. {% if r.album %} {{ r.label }} {% else %} {{ r.label }} {% endif %} {{ r.value }}
    2. {% endfor %}
{% endmacro %} {# ---- columns: value on top, bar, label underneath ------------------- `dense` (the 24-hour axis) moves the numbers out of sight but keeps them in the accessibility tree — .sr-only, not display:none, because a chart whose figures are only available to sighted readers is not a chart, it is a decoration. Every column also carries a title, so the exact figure is one hover away on a pointer device. `ticks` prints a second line under the label wherever it changes (the timeline's year), which is what lets a two-year axis read without a legend. #} {% macro cols(rows, dense=False, ticks=False, scroll=False) %} {# `scroll` wraps a long axis in its own scroller: twenty-four month columns on a 390px phone leave 13px per column, which cuts "SEP" to "SE" and runs the values together.
