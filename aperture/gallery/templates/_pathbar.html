{# The location bar — one route line, one definition, five pages. It is two things sitting on one row: the way UP (the back link, the control a phone visitor reaches for on every page) and the way BACK ANYWHERE (the trail, Home / Albums / … / here). Both wear the same face: a hairline, a glass fill, the same height. Every segment carries a mark, because the trail is scanned, not read — a house, a stack of photos, a folder, a picture. An album brings its own (album.cfg `icon =`) and that one wins; the rest fall back to the Font Awesome glyph named here. Run tools/build_fa_subset.py after changing any of them. Colour follows rule 1: the trail is grey furniture, and the ONLY accent on the row marks state — the mark of the segment you are standing on, and the border of the back link while a real pointer hovers it. The links used to be accent-purple end to end, which said "state" four times on a line where nothing had any.
