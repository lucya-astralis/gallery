It is inline SVG rather than an for one reason: an is a closed document, and nothing outside it can reach a path — no stylesheet of ours, no script of ours. The boot screen draws this mark one piece at a time and the header splits it into colour on hover, and neither is possible through an . `ghosts` adds two more copies of the wing, offset a couple of units and blended to screen. That is the chromatic split — the RGB fringe the animation is built on — and it is markup rather than a filter because a filter is the expensive way to get the same edge. The footer's mark does not move and does not pay for them. `product` swaps the wing for the product's own mark, the aperture closed down (brand kit, logo/products/gallery-mark-*.svg): the bar and the door name the product, the boot screen and the footer keep the house's eagle. It is a square, so it takes .mark--square, and it splits on hover exactly as the wing does. ================================================================== -#} {%- macro pieces(cls) -%} {%- endmacro -%} {%- macro blades(cls) -%} {%- endmacro -%} {%- macro mark(cls='', ghosts=false, product=false) -%} {%- set draw = blades if product else pieces -%} {%- set box = "0 0 100 100" if product else "0 0 964 543" -%} {%- if ghosts %}
